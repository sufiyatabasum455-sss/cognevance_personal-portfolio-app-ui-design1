# Personal Portfolio App UI Design

**Internship:** Cognevance Technologies — UI/UX Design  
**Project level:** Level 1 — Easy  
**Design tool:** Figma

## Project overview
A modern, user-friendly personal portfolio interface that presents an introduction, education/about information, skills, projects, and contact details.

## Objectives
- Create clear, low-fidelity wireframes.
- Design polished portfolio screens.
- Apply consistent typography, colors, spacing, and components.
- Create a clickable prototype for navigation.
- Consider responsive layouts for mobile and desktop.

## Screens
- Home
- About Me
- My Skills
- My Projects
- Contact Me

## Tools used
- Figma
- GitHub for project documentation and submission

## Design workflow
1. Researched portfolio design inspiration.
2. Created initial screen layouts and wireframes.
3. Designed the portfolio UI in Figma.
4. Connected navigation interactions in Prototype mode.
5. Tested the prototype and checked screen navigation.
6. Prepared screenshots and project documentation.
